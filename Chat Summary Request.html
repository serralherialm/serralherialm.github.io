Você pode subir (publicar) seu site de várias formas. Aqui estão 3 opções simples, especialmente boas para quem está começando:

1. GitHub Pages (grátis e sem precisar comprar domínio)

Ideal se você quer algo gratuito e simples.

Passos básicos:

  1. Crie uma conta no GitHub.

  2. Crie um repositório chamado nomedoseusite.github.io (ex: serralherialm.github.io).

  3. Envie os arquivos do seu site (HTML, CSS, imagens) para lá.

  4. Vá em Settings > Pages e ative o GitHub Pages.

  5. Pronto! Seu site ficará disponível em https://nomedoseusite.github.io

2. Netlify (grátis e fácil)

Permite subir o site com apenas um arquivo ZIP.

Passos:

  1. Crie uma conta em Netlify.

  2. Vá em "Add new site" > "Deploy manually".

  3. Arraste e solte a pasta ou o ZIP do seu site.

  4. Ele cria um link como https://seusite.netlify.app.

3. Contratar domínio e hospedagem (mais profissional)

Ideal se quiser um domínio personalizado tipo www.serralherialm.com.br

Passos:

  1. Compre um domínio (ex: no Registro.br, HostGator, GoDaddy).

  2. Contrate um plano de hospedagem.

  3. Envie os arquivos do site pelo gerenciador de arquivos ou FTP.

  4. Aponte o domínio para a hospedagem.

  • Não precisa pagar se usar GitHub Pages ou Netlify.

Etapa 4 – Enviar os arquivos para o GitHub

  1. No GitHub, dentro do repositório seuusuario.github.io, clique em "Add file" > "Upload files"

  2. Arraste o arquivo ZIP que você baixou ou clique em "choose your files" e selecione o .zip

  3. Descompacte dentro do GitHub (você precisa extrair os arquivos no seu computador antes e subir apenas o index.html)

  4. Após isso, clique em "Commit changes" lá embaixo

Etapa 5 – Ativar GitHub Pages

  1. Vá para a aba "Settings" do repositório

  2. No menu lateral, clique em "Pages"

  3. Em "Source", selecione a branch: main e a pasta / (root)

  4. Clique em "Save"
